Achados descartados conscientemente: Reuse sugeriu uma base class compartilhada para os 2 campos (`url`/`expires_at`) comuns a `VideoStreamResponseDto`/`VideoDownloadResponseDto`; pulado por ganho marginal (2 campos triviais, nenhum outro DTO do projeto usa base class) e por não haver precedente no código existente. Altitude também sugeriu generalizar `VIDEO_PLAYBACK_URL_TTL_SECONDS` para um nome menos específico de playback já que passou a valer também para o download; pulado por contradizer o contrato literal da API no plano, que nomeia explicitamente essa env var como a TTL de `expires_at` também em `GET /videos/:publicId/download`.
